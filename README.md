# 五子棋注释学习版（Gomoku Annotated Learning）

一个 **C++ 初学者教学项目**：用 EasyX 图形库实现的三合一棋类小游戏（五子棋 / 围棋 / 井字棋），**每个文件都带大量中文注释**，逐行讲解，适合用来学习 EasyX、游戏逻辑和 C++ 基础。

## 功能

- **三种模式**：开始页可选 五子棋 / 围棋 / 井字棋，各自带胜负判定
- **棋盘大小**：五子棋可选模板（5×5 / 9×9 / 13×13 / 15×15）或自定义（5~30 格，输入自动钳制）；围棋固定 19 路；井字棋 3×3
- **先后手选择**：黑先 / 白先
- **围棋规则**：气、吃子（同时无气一起提）、自杀禁手、提子计数（先提满 10 子者胜）
- **对局提示**：当前执棋方（带棋子图示）、围棋提子数、胜负/平局提示
- **窗口自适应**：棋盘随窗口大小居中缩放，支持三种窗口模式（窗口化 / 全屏窗口化 / 全屏）

## 编译运行

- 环境：Visual Studio 2022 + [EasyX 图形库](https://easyx.cn/)
- 打开 `五子棋注释学习版.slnx`（或直接编译 `五子棋注释学习版.vcxproj`）
- 解决方案配置选 **Debug / Release**，平台选 **x64**
- 按 `F5` 运行（或 Ctrl+F5 不调试运行）

## 文件结构

| 文件 | 作用 |
|---|---|
| `connect.h` | 数据结构与全局声明：按钮/输入框/页面结构、全局常量（UI 尺寸、围棋边界 GO_EDGE、提子胜阈 GO_WIN 等） |
| `main.cpp` | 主循环：消息处理、输入页控件显隐/点亮、落子与胜负判定、对局页绘制 |
| `page.cpp` | 六个页面的布局与按钮点击分发（含输入框失焦自动钳制） |
| `toolFunction.cpp` | 对局核心：落子、围棋气/吃子/提子/自杀判断、胜负判定、窗口三模式切换 |

## 设计要点（学习价值）

- 围棋"先判定后统一提"：同时无气的敌方组要一起提，边判边提会让第二组"起死回生"
- 围棋边界用独立的 `GO_EDGE` 常量而不是数组大小——数组 31×31 是为了五子棋 30 路预留的，棋盘外区域不能当"气"
- 提子数由 `removeGroup` 返回值累加，而不是"每提一组 +1"
- 输入框失焦自动钳制：只修刚失焦的框、空框不修正
